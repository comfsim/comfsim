# Overview

comfsim is a fork of gcsim, a Monte Carlo simulation tool used to model Genshin Impact's combat.
Please refer to [genshinsim/gcsim](https://github.com/genshinsim/gcsim)['s README.md](https://github.com/genshinsim/gcsim/blob/main/README.md) for more information.

## Getting Started

Primary usage of comfsim is through the webapp hosted via [https://fly.io](https://fly.io) at [https://comfsim.fly.dev/web](https://comfsim.fly.dev/web). Until abused, comfsim also provides a server for server-mode usage on a per-branch basis, usually at [https://comfsim-server-BRANCHNAME.fly.dev](https://comfsim-server-BRANCHNAME.fly.dev), this may include PRs at [https://comfsim-server-BRANCHNAME.fly.dev](https://comfsim-server-pr-BRANCHNAME.fly.dev) after manual review.

Any issues or questions specific to comfsim can be directed to @TheSast, whom can be contacted via discord at [TheSast#5457](https://discordapp.com/TheSast#5457), I am also present in the official gcsim discord.
If you are reaching out for an issue (e.g. a bug), please make sure that it is a comfsim specific problem, otherwise you'd be better served by reporting it upstream.

## Why fork?

Primarily to allow those whom wish to add features with a lower standard for quality to contribute indirectly to gcsim.
If you have any ideas at all on how to make comfsim useful in other ways, feel free to bring it up!

## How fork is fork?

To see how this fork differs from upstream, check [genshinsim:gcsim:main...comfsim:comfsim:comf](https://github.com/genshinsim/gcsim/compare/main...comfsim:comfsim:comf).
